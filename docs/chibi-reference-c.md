# Chibi face reference audit — JJK, Hunter x Hunter, Kakegurui, Firefly Wedding, Yona

The product/gallery images below were visually inspected for this revision, including their eye openings, iris proportions, brow angles, and mouth expressions. They are references for original SVG redraws; no reference images are shipped in the application. A specific merchandise face plate is one expression choice, not a claim that a character always wears it. Where an individual chibi could not be verified, the fallback is explicitly identified.

## Firefly Wedding

[Official mini-anime episode 1](https://www.youtube.com/watch?v=A2ZuZt01_Po) uses actual simplified chibis. Its thumbnail was visually inspected: Satoko has downturned heavy upper lids and a tiny flat mouth; Kotaro has a restrained horizontal gaze. The [official character sheets](https://hotaru-anime.com/character/) supplement these silhouettes. Shinpei, Asagiri and Mitsueda use cast/manga expression fallbacks because individual chibi plates were not verified.

| Character | Applied face direction |
| --- | --- |
| Satoko | Small quiet mouth, concerned half-lidded eyes and restrained blush; pale center-part hair. |
| Shinpei | Narrow intent eyes, small pupils, unsettling wider tooth grin, long pointed lower face. |
| Kotaro | Calm low lids and straight small mouth; adult squared lower face. |
| Asagiri | Lifted outer lashes, composed small colored mouth, elegant oval face; manga reference fallback. |
| Mitsueda | Heavy narrow eyes and small pupils, tired lower-eye lines, crooked mouth and stubble; cast fallback. |
